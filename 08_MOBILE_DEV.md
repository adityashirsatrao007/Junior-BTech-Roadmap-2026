# 08 — Android / iOS Development from Zero

Pick **ONE** platform. iOS needs a Mac for building; Android runs on any laptop → **most students: pick Android (Kotlin)**. Only switch to iOS if you own a Mac.

---

## 1. Decide your path

| Path | Tools | Best for | Cost |
|------|-------|----------|------|
| **Android (native)** | Kotlin + Android Studio | most jobs in India, easier setup | Free |
| **Flutter (cross-platform)** | Dart | one codebase → Android + iOS apps | Free |
| **React Native** | JS + React (you already know this!) | reuse your full-stack JS skills | Free |
| iOS (Swift) | Xcode, needs a Mac | Apple-only shops | Needs Mac |

**Recommended:** if you already did `06_FULLSTACK` → **React Native or Flutter** (reuse skills). Pure Android dev fans → native Kotlin.

---

## 2. Learning order (Android/Kotlin, 4 weeks to first app)

1. **Kotlin basics** (variables, functions, classes, null-safety) — it's a friendlier Java.
2. **Android Studio install** + first "Hello World" emulator run (Day-1 style check).
3. **UI fundamentals**: activities, layouts, RecyclerView, buttons/intents.
4. **State & navigation** — build a 2-screen app.
5. **Data:** store with Room (SQLite) or Firebase; call REST APIs with Retrofit.
6. **Publish:** generate signed APK → (optionally) Google Play $25 one-time.

**Resources (all free):**
- roadmap.sh/android (visual map) · github.com/amitshekhariitbhu/android-developer-roadmap

---

## 3. What to build (resume-ready, in order)

1. Todo/notes app with local storage (Week 1-2)
2. Weather app calling a free API (Week 3) — shows you can integrate network
3. **Your own idea** — pick something you actually want (fitness tracker, college event app, movie DB). Skip clones that 500 others have.
4. Deploy an APK + a demo video + GitHub README.

---

## DO / DON'T

**DO** — ship 2 complete apps over 1 polished; learn to run on a real phone (USB debugging); keep screenshots + demo for GitHub.
**DON'T** — rebuild the tutorial app 10 times; neglect version control (commit each app!); try to learn Android + Flutter + iOS simultaneously.
