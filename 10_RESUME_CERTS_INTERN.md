# 10 — Resume, Certifications, Internships, Unstop

This file turns your DSA + projects into **offers**. Tools: **Overleaf** (LaTeX resume), **Unstop** (Indian internship/contests portal), free certs for the resume.

---

## 1. Resume on Overleaf (Do this ONCE, iterate forever)

Strings of LaTeX resume templates are one click away — they look far better than MS Word.

1. Create account at **overleaf.com** (free).
2. New project → Browse templates → search the "**Jake's Resume**" template (clean, single-page, used by thousands).
3. Replace the sample with your real data. Keep it **one page** until you have 2+ yrs experience.
4. Compile → PDF → save the PDF as `Aditya_Resume.pdf` in this repo's `resume/` folder. Keep that folder git-committed.

**A recruiter reads it for ~10 seconds.** Rule = every line must answer: "what did *you* do, and what *result* came from it?"

- Quantify: "Built REST API (FastAPI) reducing response time by 35%" beats "Worked on APIs".
- Projects section: name → 1 line what it does → tech stack → 1 bullet result.
- Skills section: group (Languages / Web / DevOps / ML) in little tags.

## 2. Free certifications for the resume (in order of value)

Fill gaps, not checkboxes. Each is 1–2 weekends, free, linkedin-friendly.

| Cert | Why | Cost | Do it when |
|------|-----|------|-----------|
| **GitHub** certifications (GitHub Actions / Cloud Foundations) | recruiters see Git seriously | Free | after `05` |
| **freeCodeCamp** Responsive Web Design / JS | proof of full-stack basics | Free | alongside `06` |
| **Google**: (a) Machine Learning Specialization is paid, but **Generative AI** free courses certify | AI-adjacent roles | Free | in ML phase |
| **Microsoft Learn** AI Fundamentals AI-900 / Azure Data Fundamentals | cloud+AI signal | Free | before internships |
| **HackerRank** skill badges (coding) | quick proof, zero cost | Free | any down-time |

**Don't** list course-completion certs you can't name a skill from. 3–4 strong certs > wall of badges.

## 3. Internships — the fastest route to a job

Pipeline (repeat monthly from P2 onwards):
1. **Fix portfolio**: resume PDF + 2–4 GitHub repos + LeetCode badge on resume header.
2. **Unstop** (unstop.com) → create student profile → filter **Internships** → apply to 5–10/wk:
   - use the "free internship alerts" pages + company's LinkedIn job posts.
3. **Interview prep per role**: SWE → DSA+OS; Data → SQL+statistics; Full-Stack → your 2 projects underground.
4. Take **unpaid-but-real** first (make it a 2-week commitment, get work samples + a letter), then aim paid.
5. Each application: 2-3 line intro where you link ONE relevant repo.

Software interns that ship a feature *quietly* convert to full-time more than star performers who don't.

## 4. Unstop (your India-centric launchpad)

**unstop.com** = contests/hackathons/internships by Indian companies + campus drives.

- Complete the **profile 100%** (education, skills, links) — before events count.
- **Contests/events section**: filter free; many give *participation certificate* proof and interview pipelines.
- Use their **mock tests** for the company-specific aptitude.
- Campus drives from your university usually link here — enroll and track.

Unstop is where your `09` aptitude practice meets concrete employer opportunities.

---

## 5. Weekly application rhythm (once started)

**Every Sat (10:30−11:00 slot):** 5 applications + 1 informational LinkedIn message to a campus alum in target company. 20 apps/month at 70/30 quality keeps you in pipeline long enough for an intuitive "why pick me" story.
